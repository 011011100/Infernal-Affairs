# 无间风云线上版规则

本项目是一套供朋友组局的非官方线上实现。第一版使用经典 16 张装备牌组，并采用官方后续修订的卡牌效果；不是第四版扩展规则。身份、装备名称及说明由本项目用中文重新表述，界面未使用原版卡面或插画。

## 人数与获胜条件

4～8 人。每人有三张身份牌，只有本人可以看见自己的全部身份。

- 持有「探长」的人属于忠警阵营；持有「主谋」的人属于黑警阵营。
- 没有首领身份时，三张普通身份的多数决定阵营。
- 忠警阵营击败主谋获胜，黑警阵营击败探长获胜。击败己方首领同样会让对方阵营获胜。
- 如果任何存活玩家通过交换同时持有探长和主谋，立即独自获胜。
- 玩家可能因身份交换或「栽赃」改变阵营。已出局者不参与操作，但其阵营仍可获胜。

## 开局

| 人数 | 探长 | 主谋 | 忠警普通身份 | 黑警普通身份 | 枪  |
| ---- | ---- | ---- | ------------ | ------------ | --- |
| 4    | 1    | 1    | 5            | 5            | 2   |
| 5    | 1    | 1    | 7            | 7            | 3   |
| 6    | 1    | 1    | 8            | 8            | 3   |
| 7    | 1    | 1    | 10           | 10           | 4   |
| 8    | 1    | 1    | 11           | 11           | 4   |

先将两张首领和随机抽出的「人数减二」张普通身份混洗，每人发一张，再给每人两张普通身份。这样开局的两位首领一定在不同玩家手中。5 人与 7 人局各有一张普通身份不会发出。

每人随机获得一张装备；随机选择先手。每局均使用完整的 16 张经典装备，不按旧实体卡上的人数角标移除装备。

## 每回合

在自己的行动阶段选择且仅选择一种行动。使用装备不占用这个行动。

| 行动   | 效果                                                                                     |
| ------ | ---------------------------------------------------------------------------------------- |
| 调查   | 查看其他存活玩家的一张未公开身份。只有调查者会获得这条情报。                             |
| 拿枪   | 从公共区拿一把枪，公开自己选择的一张未公开身份，并在回合末选择瞄准目标。每人最多一把枪。 |
| 拿装备 | 抽一张装备，公开自己选择的一张未公开身份。若已有一张装备，须在两张中保留一张。           |
| 射击   | 向自己此前瞄准的存活玩家开枪；宣告后进入 6 秒装备响应时间。                              |

自己的三张身份已经全部公开时，拿枪和拿装备仍可执行，无须额外公开身份。

正常行动完成后，若持枪，必须选择瞄准一名其他存活玩家；也可以保留仍然有效的原目标。选择瞄准即结束回合。无枪则直接轮到下一名存活玩家。不能用「结束回合」跳过必需的正常行动。

除特定装备效果外，不能在回合外改瞄，也不能在一次回合里先改瞄、再用正常行动射击。瞄准对象若已出局，枪不会自动指向别人；应先做调查或拿装备等合法行动，在回合末重新瞄准。

## 中枪与淘汰

射击结算时，射手的枪回到公共区，被击中玩家的三张身份全部公开。

- 普通玩家中一枪即出局，装备放回牌堆底，持有的枪回到公共区。
- 首领第一次中枪时受伤，继续存活，并立即抽一张装备；若超过一张，必须先择留。
- 受伤首领再次中枪即出局，对方阵营立即获胜。
- 伤势标记跟随首领身份牌移动。交换走受伤首领牌的原持有人不再受伤；新持有人继承伤势。

## 装备

除牌上列出的条件外，存活玩家可在任意人的回合使用装备。单张装备需完整结算，才能使用下一张。手持装备最多一张；取得新装备导致超限时，必须先选择保留，不能先使用多出来的装备逃避弃牌。

一般使用完或弃掉的装备放回牌堆底。「栽赃」和「烟雾弹」留在桌面，不回到牌堆。

| 装备       | 使用条件与效果                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 勒索       | 交换另外两名存活玩家各一张身份；不能选择自己。明暗、伤势及已有调查情报跟随实际卡牌移动。               |
| 咖啡       | 在他人回合使用。该回合结束后立即轮到你，之后从你的位置按当前方向继续。                                 |
| 除颤器     | 复活另一名已出局玩家。其身份仍然公开，不补回原来的装备或枪。首领出局会立即结束游戏，不能事后复活首领。 |
| 证物袋     | 把第一名玩家的手持装备交给第二名玩家。接收者不能是使用者；若超限，由接收者先择留。                     |
| 闪光弹     | 选择一名存活玩家，将其三张身份洗乱并全部盖回。旧调查记录全部清除；本人重新看到自己的身份。             |
| 警犬       | 令一名持枪玩家交回枪。若对正在宣告射击的射手使用，射击被阻止，射手可以重新选择正常行动。               |
| 金属探测器 | 依次查看每名其他持枪玩家的一张未公开身份；每名目标均由装备使用者选牌。                                 |
| 栽赃       | 留在一名玩家面前，该玩家的普通忠警身份按黑警计算、黑警身份按忠警计算。首领身份不受影响。               |
| 测谎仪     | 你与另一名存活玩家互相查看对方全部身份。情报只给这两人。                                               |
| 档案审查   | 所有仍有未公开身份的存活玩家，依次自行选择公开一张。                                                   |
| 限制令     | 仅在射击响应阶段使用。射手必须自行改选另一名存活玩家，不能射自己，随后继续射击。                       |
| 烟雾弹     | 永久反转回合轮转方向。                                                                                 |
| 监控摄像头 | 在最近一次正常调查行动后、下一次正常行动前使用，公开刚被调查的身份。不是第四版的持续反调查效果。       |
| 电击枪     | 自己回合且没有枪时，夺走另一名玩家的枪并立即瞄准对方。仍可进行正常行动，但本回合不能射击。             |
| 吐真剂     | 指定一名存活玩家，由该玩家自己选择公开一张未公开身份。                                                 |
| 窃听器     | 查看两名不同的其他存活玩家各一张未公开身份。                                                           |

## 线上时序与情报处理

- 宣告射击后有 6 秒响应期，这是线上适配规则，实体游戏没有固定秒数。限制令导致射手选择新目标后，新目标会得到完整的 6 秒响应期。
- 装备若要求玩家选牌、择留或重新瞄准，会暂停其他操作。完成后恢复原阶段；射击计时若已结束，将在选择完成后结算。
- 监控摄像头采用「下一次正常行动前」的响应范围。若目标身份被闪光弹洗乱，或该槽位在响应前被勒索交换，摄像头的旧响应记录会清除，避免公开无关身份。
- 勒索按卡牌实体追踪情报，旧主人也记得自己交出的牌。闪光弹会清除所有人对那三张牌的旧记录。
- 已知身份由服务器分别投影给每一名玩家；未调查的身份、他人手牌、牌堆和其他人的调查记录不会发送给客户端。对局结束后公开全部身份。
- 断线不会自动投降或消灭首领，原座位保留用于重连。轮到断线玩家操作时，房主可在服务端规定的等待时间后跳过；若卡在装备选择流程，则采用合法默认选择完成当前步骤。
- 第一版仅支持预设表情互动，不包含语音、视频或文字聊天。
